| `t2t_h9_v01_hap1.fa` | ~ 3 GB | UCSC Genome Browser — H9 T2T diploid |
| `t2t_h9_v01_hap2.fa` | ~ 3 GB | UCSC Genome Browser — H9 T2T diploid |

| `H9_HAP2.gtf` | ~ 40 MB | UCSC CAT pipeline |

**Patil et al. bioRxiv 2026.03.26.714432** — <https://www.biorxiv.org/content/10.64898/2026.03.26.714432v1>

### AlphaGenome API access

AlphaGenome variant scoring requires an API key from Google DeepMind:
<https://deepmind.google/alphagenome>

Set the key as an environment variable before running `scripts/09_score_alphagenome.py`:

```bash
export ALPHAGENOME_API_KEY="your-key-here"
```

## What's hosted in the repo (so you may not need everything above)

If you only want to inspect or extend the **final results** (priority shortlist, AlphaGenome summary, ASE counts) and re-run figures, you do **not** need any of the large external files — everything required is already committed under `results/` and `data/small_inputs/`.

The external files are required only for re-running the full pipeline from raw sequence data.
